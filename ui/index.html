工作台

「工作台」是可选的设备统一管理工作台（独立面板，端口 3000），用于管理本机设备 / 服务。
intent 聊天 Agent 本身完全独立运行（三端口 6800/6801/6802 + 本窗口），不依赖工作台。如果只用聊天 Agent，可以把这个入口关掉，等于把工作台插件剥离。
工作台后端已改为纯标准库实现（不再需要 uvicorn / fastapi / pyyaml），点击侧栏「工作台」会自动拉起并打开面板。
关闭后侧栏不再出现该按钮，聊天 Agent 一切照常；想恢复时回到这里勾上即可。也可直接编辑 配置.qdai 写 workbench_enabled=0。
