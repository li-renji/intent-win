赛车少年桌宠 · 交互原型（用现有素材做的可看版本）
================================================

一、这是什么
用工程包里"现有素材"做出的可运行原型，用来先验证方向对不对：
角色常驻桌面 + 气泡、背景真透明、有交互。你看过没问题，再去做新素材。
它不是正式版，不改动 D:/INTENT-win/plugins/ajue/ 里的现有插件。

二、怎么看（两种方式）
1) 浏览器预览：直接打开「预览.html」
   - 模拟桌面环境，能看到角色常驻、透明背景、点击/双击/拖拽/右键菜单/气泡/闲置动作
   - 右上角有「对比旧版白块效果」开关，可直接看出透明问题解决前后
2) 真桌面桌宠：双击「启动桌宠.bat」
   - 角色真的浮在桌面上、置顶、背景透明
   - 单击=挥手 / 双击=跳一下 / 拖动=移动 / 右键=菜单 / 闲置 9~15 秒=随机思考或坐下
   - 位置会记在 pet_pos.json；右键「让阿觉休息」退出
   - 需要 C:\Python314\python.exe（本机已验证 tkinter + Pillow 齐全）
   - 静态待机**完全静止**：图片态不做任何上下浮动/呼吸位移
     （2026-11-05 修复：原来每 1.7 秒瞬移 5px，看着像轻微闪动）
   - 启动窗口里是英文提示（bat 必须纯 ASCII，中文在 cmd 里会乱码成"命令"），
     中文对照：Click=挥手、DoubleClick=跳一下、Drag=移动、RightClick=菜单。
     成功启动后这个黑窗口可最小化，关掉它等于关掉桌宠。
   - 2026-11-05 修复：bat 改为纯 ASCII + CRLF，Python 入口改名 desktop_pet.py，
     彻底避开 GBK/UTF-8 代码页导致的「中文被当成命令」「找不到路径」。

四、现有素材的真实情况（体检结论）
  1. 工程包「素材-图片视频/pet_main.png」和「pet_main_transparent.png」
     其实都是 JPEG（文件头 FFD8 FFEB），只是后缀写成 .png，都没有透明通道。
     你 11-02 更新的那张 882KB「透明图」也一样是 JPEG。
  2. 4 段视频是白底（RGB 235~245）+ 淡斜纹，不是说明.txt 要求的纯绿幕 #00E676，
     HEVC 720x720 / 24fps / 121 帧（5 秒）。
  3. 角色本身有大量白色（帽/脸/衣/鞋），所以不能用全局色键抠白，会把角色抠穿。
     本原型改用「从四边做连通域去背」：只去掉与画面边界连通的浅灰白，
     角色内部的白色因为有完整深色描边、不与边界连通，全部保住。
  4. 静态立绘与视频不是同一批画面（表情不同、角色宽度 99px vs 118px），
     直接混用会在动作切换时"变脸 + 跳大小"。
     所以待机态改用视频首帧，保证同源；静态立绘只留作参考。
  5. 插件 assets 里那张真 RGBA 透明 PNG 是「黑衣版」，与视频「白衣版」不是同一形象，
     本原型统一用白衣版（你较新的那版）。

五、为什么没用 WebM
  说明.txt 要求绿幕 -> 抠像 -> 带 Alpha WebM。本机 ffmpeg 9.0.2 的 VP9/VP8
  编码实测会丢掉 alpha（输出 yuv420p，抽帧四角 alpha=255），播出来仍是白底方块。
  自验收不通过，所以没把 WebM 交付，改用带 Alpha 的 animated WebP + PNG 帧序列，
  两者都已抽帧验证四角 alpha=0。等你补纯绿幕新素材后，换工具链再补 WebM。

六、技术路线说明（为什么没用 pywebview）
  原来的 runner.py 用 pywebview + SetWindowRgn 裁圆，所以是白色圆块。
  实测本机：
    - pywebview transparent=True 不生效（圆外仍是白块）
    - Win32 分层窗口 LWA_COLORKEY 也不生效（WebView2 走 DirectComposition，GDI 色键管不到）
  所以原型改用 tkinter + -transparentcolor：窗口自身绘制，色键生效，
  透明区鼠标天然穿透到桌面，角色像素可点可拖。已用截图 + 模拟点击验证。
  正式版若要保留 HTML 气泡/复杂 UI，需要走「按像素 alpha 命中测试」的分层窗口，
  那是阶段 2 的正式工作。

七、验收用环境变量（正常双击完全不用管）
  PET_AUTO_EXIT=<秒>   到时自动退出，供自动化实跑验收，不留残留进程
  PET_POS=x,y          指定独立窗口位置，避免与已运行的桌宠实例重叠
  PET_NO_IDLE=1        关闭闲置随机动作，隔离出「纯静态显示」用于像素级比对
  验收脚本 验收/test_static.py：连拍 5 张、跨 8.8 秒，逐张比对 57600 像素，
  差异全为 0 才算 PASS。2026-11-05 实测 PASS。
  注：闲置随机动作（9~15 秒自动思考/坐下）是**有意设计**，不是闪动；
      如果也觉得打扰，可以调长间隔或整体关掉。
