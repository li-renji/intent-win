intent-win 扩展中心

intent-win 自带扩展系统：技能（.qdskill）与插件（.qdplugin）都是文件驱动的， 装进目录即可用。本页把本机做好的扩展打包成可下载的静态站点，在另一台电脑上几分钟就能装齐。

— 静态站点 · 无需后端 不含任何个人数据 一键安装脚本

快速开始（三步）

  1. 下载安装器 install.py（点下面的按钮）。
  2. 在 intent-win 的根目录（就是有 agent/、plugins/ 的那一层）打开命令行，执行：
    python install.py 复制
  3. 重启 intent——技能摘要与插件注册都在启动时完成，重启后才生效。

装完打开「设置 → 市场」能看到新装的扩展；桌宠阿觉的 常驻监听与开机自启都在它自己的「设置 → 监听」页里开关。

⬇ 下载一键安装器（Windows 双击即可） ⬇ 只下载 install.py 单文件自包含 · 离线可用

三种安装方式

方式一：一键安装（推荐）

一条命令装齐全部扩展，同时把配套的运行时代码放到正确位置（光装 manifest 是不够的—— 插件的 run 会去调用仓库里的脚本）。

python install.py --root D:\intent-win

只装某几个：python install.py --only ajue,workbench,genoffice

方式二：URL 安装（只补单个扩展）

已经装好 intent-win、只想再补一个扩展时最快：

  1. 打开 intent 的 设置 → 市场 → URL 安装。
  2. 类型选 skill 或 plugin（见下方清单里的「类型」列）。
  3. 地址填下面清单里对应扩展的下载链接，id 填它的 id。
  4. 确定后重启 intent。

注意：URL 安装只能装单个 manifest，不带配套代码。像「阿觉常驻监听」这种 需要配套脚本的，请用方式一。
另外：下载链接要整条复制（含后面的 ?sharecode=… 访问码）， 只复制前半段会返回 403。

方式三：手动放置

直接下载文件，放到对应目录即可：技能放 <根目录>/skills/， 插件放 <根目录>/plugins/；再重启 intent。

重点：阿觉常驻语音监听

桌宠「阿觉」新增的常驻监听能力——插着充电器时在后台一直听你说话， 听到「阿觉」才唤醒，回答后用语音回应，全过程无弹窗。

额外依赖（只在用监听时才需要）

pip install faster-whisper sounddevice pypinyin zhconv

faster-whisper 首次运行会下载模型（约 140 MB）；国内网络建议设置 HF_ENDPOINT=https://hf-mirror.com 与 HF_HUB_DISABLE_XET=1 （本页提供的 listen.py 已内置这两个兜底）。

怎么用

  • 点桌宠 → ⚙ 设置 → 监听 页；
  • 打开「启用常驻监听」——它会一直听你说「阿觉」，确认是叫它才回答；
  • 再打开「开机自启」——开机后阿觉在后台无窗口地守着（写当前用户启动项，无需管理员权限）。

这两项都是阿觉插件自己的设置，不需要额外安装任何扩展。

可调项

唤醒词（默认「阿觉」，可多个）、识别模型（tiny / base / small）、电量策略（仅插电 / 始终）。 改完约 2 秒内生效，不用重启。

注意事项

隐私 本站只含扩展代码本身：不含 配置.qdai（里面是 API Key）、 不含 plugin_data/（聊天记录 / 日记 / 长期记忆）、不含任何会话文件。 这些永远只留在你自己机器上。

依赖 「工作台」技能依赖 workbench/ 目录与 Node 前端；「GenOffice」依赖外部 GenOffice CLI；「VS Code 面板」「网页 DeepSeek」依赖各自的 tools 适配器与登录态。 这些扩展的 manifest 可以装上，但要真正跑起来还需要对应的环境。

网络 「工作台」技能正文里写死了内网地址与 MeshCentral 账号，换网络环境时需要自行修改。
