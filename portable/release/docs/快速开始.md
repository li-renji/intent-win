# 快速开始（clone 后照做，10 分钟内跑起来）

## 0. 先体检（强烈建议）

```bat
python 构建检查.py
```

它会一次性告诉你：Python 版本够不够、pywebview 装没装、配置里还有哪些占位符没填、
全部测试通不通过。**有阻塞项它会在结尾列出，按提示修即可。**

## 1. 装依赖（只有 1 个）

```bat
python -m pip install -r requirements.txt
```

依赖只有 `pywebview`。不装也能跑（三端口引擎、工具、Agent 循环、本地推理都不依赖它），
但聊天窗口与内置浏览器会降级为「未启用」。

## 2. 填配置（打开 `配置.qdai`）

至少要填这三行（`构建检查.py` 会指出具体行号）：

```
llm_mode=cloud
base_url=http://你的手机IP:9999/v1     # 手机端起点OS mini 提供的 OpenAI 兼容端点
api_key=你的网关Key
model=qwen2.5-1.5b-mnn
```

> 仓库里这三行是占位符 `<你的API Key>` / `<手机IP>`，**必须替换成你自己的**。
> 用云端 API（DeepSeek / 通义 / OpenAI 等）也一样：把 base_url、api_key、model 换成对应值即可。

## 3. 启动

```bat
start.bat
```

或命令行：

```bat
python -m agent.app        # 聊天窗口形态（推荐）
python -m agent.main       # 只要三端口引擎，不开聊天窗
```

首次启动会弹防火墙询问（本地服务），点**允许**。

## 4. 验证

```bat
python -u test_pc_bridge.py       # 文件桥 18 项
python -u test_local_engine.py    # 本地引擎 22 项
python -u test_local_api_e2e.py   # 本地模型对外 API 7 项
```

另开终端敲引擎：

```bat
nc 127.0.0.1 6800        :: 然后输入 STATUS / HELLO
curl http://127.0.0.1:6802/v1/models
```

## 5. 可选：本地内置模型（不连手机也能跑）

```bat
:: ① 下载 llama.cpp Windows 发行包，把 llama-server.exe 路径填进 配置.qdai 的 local_engine_binary
:: ② 把 GGUF 模型放进 models\<模型名>\
python -u -m agent.model_mgr scan             :: 识别到哪些模型
python -u -m agent.model_mgr recommend 11.8    :: 按内存推荐（本机 11.8GB 填你的实际内存）
:: ③ 填 local_engine_model 后，外部程序打 http://127.0.0.1:6802/v1/chat/completions 即由本地引擎作答
```

> 本机参考配置：Intel Celeron N5095A（4 核）、无独显、11.8GB 内存 →
> 属纯 CPU 小机器，建议 **1.5B~3B 的 Q4 量化模型**，`local_engine_gpu_layers` 必须保持 0。

## 6. 打可分发的包

```bat
python 构建检查.py --zip
```

产出 `qd-agent-win-可运行版.zip`（自动排除 `shots/`、`会话/`、`*.log`、`pc_bridge.token`、
`models/` 内容与 `__pycache__`，不会把你的聊天记录和密钥打进去）。

## 常见问题

| 现象 | 原因 / 解决 |
|---|---|
| 双击 start.bat 一闪而过 | 依赖没装 → 先跑第 1 步 |
| 界面提示「未配置 API Key」 | 第 2 步的占位符没替换 |
| 连接手机超时 | 手机深度睡眠了 → 解锁手机并打开起点OS mini |
| 本地引擎起不来 | 先跑 `python 构建检查.py`：多半是二进制路径没填或 `n-gpu-layers` 非 0（本机无独显必须为 0） |


## v5 新功能速用（2026-10-25）

**模型库自动入库**：设置里把云端 API（Base URL / Key / 模型名）填完整 → 保存 →
提示"已自动存入模型库：模型 @ 域名"。下次在「模型档案」下拉里直接选，或改完再保存自动更新。

**知识库**：首次启动后自动后台扫描（设置页可看"已索引 N 个文件"）。
对话里直接说"帮我找一下叫XX的文件"，Agent 会用 KB 工具秒查；
设置页也可手动检索/重新扫描。手机端连上「电脑文件桥」后可用 `/kb/search` 查同一份索引。

**记忆**：对话里说"记住……"即写入；设置页「记忆」区查看全部。

**语音输入**：点输入框右侧 🎤 → 说话 → 文字自动填入。说中文需先在
「设置 → 时间和语言 → 语音」里添加中文语言包。

**更省 token**：已对标 pi 的做法——系统提示精简、工具结果头尾截断、
fs 大文件分段读（offset/limit）、上下文用掉 80% 自动压缩早期历史。
实测压缩可省约 70% 的历史 token。
